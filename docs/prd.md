# KnowledgeCast PRD

## 结论

定位：面向讲师 / 培训师 / 知识型从业者，把碎片知识快速整理成**可讲、可发、可复用**的培训网页。

核心链路：`碎片知识输入 → AI 结构化整理 → 生成培训/宣讲内容 → 以网页形式输出`

首选客群：个人讲师、独立顾问、培训博主。

扩展客群：企业内训/L&D、销售赋能、产品赋能、创业者内部分享、知识型内容创作者。

核心痛点：
1. 先找到独特且有价值的培训框架
2. 再把零散素材/经验/想法消化成结构化内容

产品边界：不是泛知识管理，也不是大而全内容平台。

## 目标用户

| 层级 | 用户 | 痛点 |
|------|------|------|
| 首选 | 个人讲师、独立顾问、培训博主 | 缺少独特框架 + 碎片素材难结构化 |
| 扩展 | 企业内训/L&D、销售赋能、产品赋能、创业者内部分享、知识型内容创作者 | 培训内容制作和更新成本高 |

## 核心场景

1. **讲师备课** — 收集碎片想法和素材 → AI 按框架整理 → 生成幻灯片 → 分享给学员
2. **迭代优化** — 讲完后发现问题 → 用自然语言指令调整内容 → 重新生成
3. **多场培训** — 同一套素材，换不同框架和主题 → 面向不同受众生成不同版本

## 用户故事

### P0（已完成）

- 作为讲师，我能按业务方向创建多个工作区（Area），每个工作区下创建多个工作集（Collection）
- 我能通过左侧侧边栏树形导航，拖拽排序工作区和工作集，跨工作区移动工作集
- 我能通过工作集 Dashboard 一目了然看到素材数、培训页数，通过卡片入口进入采集/整理/发布
- 作为讲师，我能快速采集碎片知识（文本/链接/Markdown），系统自动识别类型并 AI 生成标题。采集分两种模式：「捕获素材」原样保存不穿透 URL，「提取 URL 素材」通过 MarkItDown 批量获取页面正文并下载图片
- 采集的素材支持内联编辑标题和源码，支持手动 AI 重新生成标题，支持删除（自动清理未被引用的图片）。素材库中正文默认以 Markdown 渲染显示（含图片），hover 显示编辑源码入口
- 我能从 5 套内置培训框架中选择，或创建自己的自定义培训框架
- AI 按框架将碎片组织为幻灯片（标题、要点、讲者备注、时长预估）
- 工作集的培训主题描述自动注入 AI 生成上下文
- 我能通过自然语言指令让 AI 重新调整内容，生成结果持久化不丢失
- 我能生成私密分享链接，学员需邮箱验证才能查看
- 作为创建者，我能直接预览培训页（`?preview=1`），跳过验证
- 学员看到的培训页是幻灯片形式，讲者备注默认展开
- 我能通过顶部导航栏的统一标签导航（采集/整理/发布/设置）在工作集内自由切换，无需在每个页面重复操作导航
- 我能通过顶部导航栏右侧用户菜单进入 AI 模型设置，自行配置 DeepSeek 或 OpenAI 的 API Key（BYOK），配置参数包括 Provider、API Key、Model、Temperature、Max Tokens。API Key 加密存储。AI 配置不完整时系统明确提示，不回退到环境变量
- 工作集设置页删除工作集采用两步确认（展开面板 + 输入名称匹配），明确提示素材不会被删除
- 删除工作集后，素材保留在系统中，进入「未归类素材」视图。我能通过侧边栏底部入口进入该视图，将脱离工作集的素材转移到任意工作集
- 工作集无素材时，整理页自动引导我回到采集页；无培训页时，发布页自动引导我回到整理页
- AI 操作失败时（API Key 未配置、生成失败等），我能看到明确的原因说明而非笼统的错误提示
- 我能看到每次 AI 生成/迭代的版本历史，预览任意历史版本并一键恢复
- 生成幻灯片后，我能看到素材覆盖了框架的哪些环节，哪些环节还缺素材（生成前也有素材数量提示）
- 我能直接点击幻灯片标题、要点、讲者备注进行内联编辑，修正细节不必重新走 AI

## 核心概念

| 概念 | 定义 |
|------|------|
| 工作区（Area） | 按业务方向划分的顶层容器（如「企业内训」「个人品牌」） |
| 工作集（Collection） | 一个培训主题的素材容器，归属于某个工作区。所有碎片和培训页归入工作集 |
| 素材 | 一条碎片知识（文本/链接/Markdown），有 AI 生成的标题，可人工编辑或删除 |
| 框架 | 培训结构模板。内置 5 套 + 用户可自定义，定义幻灯片的章节顺序 |
| 幻灯片 | AI 生成的最小输出单元。包含标题、要点、讲者备注、预估时长 |
| 迭代 | 用户通过自然语言指令让 AI 调整已生成的内容 |
| 培训主题 | 工作集级别的文本描述（培训目的、受众），注入 AI 生成上下文 |
| 未归类素材 | 脱离工作集的素材（来自删除工作集操作），可被重新分配到任意工作集 |
| BYOK | 用户自行提供和管理 AI 服务商的 API Key，系统不内置服务商密钥 |

## 核心流程

```
创建/选择工作区和工作集 → 采集素材 → 选择框架 → AI 生成幻灯片 → 调整迭代 → 分享
        ↑                                                                   ↓
        └──────────────────── 可无限循环 ←─────────────────────────────────┘
```

## 非目标（明确不做）

- 不是泛知识管理/笔记工具
- 不是在线文档编辑器（不能直接编辑幻灯片内容）
- MVP 不做语音输入
- MVP 不做协作编辑
- 不追求绝对防复制
